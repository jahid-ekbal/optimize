# TEAM REGIX - Professional System Optimizer v3

A comprehensive Windows system optimization and maintenance tool designed for professionals and power users.

## Description

TEAM REGIX Professional System Optimizer v3 is a powerful batch script utility that provides comprehensive system maintenance, optimization, and diagnostic features for Windows environments. This tool helps users clean temporary files, optimize network settings, monitor system performance, and maintain overall system health.

## Features

- **System Information Display** - View detailed Windows version, CPU, and system specifications
- **Temporary Files Cleanup** - Remove unnecessary system temporary files
- **Network Optimization** - Flush DNS cache and renew IP address for better connectivity
- **System Cache Cleaning** - Clear prefetch and browser cache for improved performance
- **Disk Analysis** - Comprehensive disk usage and free space reporting
- **Performance Monitoring** - Real-time CPU, memory, and system uptime statistics
- **Event Log Management** - Clear Windows Event Logs for system efficiency
- **Administrator Elevation** - Automatic privilege escalation for advanced features

## Safety Features

- **Read-Only Operations** - System information and diagnostics are non-destructive
- **Safety Ratings** - Each feature is clearly marked with safety level
- **Administrator Verification** - Requires elevated privileges for sensitive operations
- **User Authentication** - Secure login system for tool access
